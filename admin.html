📤 Export to Website

Follow these steps to publish your properties on the main website (index.html).

  1. Click "Export Properties Code" below This generates the HTML code for all your active properties. A file will download automatically.
  2. Open your index.html file in Notepad Right-click on index.html → Open With → Notepad (or any text editor).
  3. Find this section in the file
    <!-- PROPERTIES START -->
  4. Replace everything between START and END with the exported code Delete the old property cards and paste the new code from the exported file.
  5. Save and refresh your website Your new properties will appear instantly!
