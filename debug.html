🔍 Properties Debug Tool

Use this tool to diagnose why properties aren't showing on your website.

📌 How to use this tool:
  1. Upload this file (debug.html) to your GitHub repo in the same folder as index.html
  2. Access it at: https://therocks03.github.io/JaipurPrimeEstate/debug.html
  3. Click "Check localStorage" to see if properties are saved
  4. Click "Add Test Property" to add a sample property
  5. Go to your main page to see if it appears
Click "Check localStorage" to begin...

Step 1: Check if Data is Saved

The "Check localStorage" button above will show you if properties are being saved properly.

Step 2: Add a Test Property

Click "Add Test Property" to add a sample property. Then check your main page.

Step 3: Verify Same Domain

Current URL:

Your admin should be: https://therocks03.github.io/JaipurPrimeEstate/admin.html

Your index should be: https://therocks03.github.io/JaipurPrimeEstate/index.html

⚠️ If URLs don't match exactly, localStorage won't work!
